Modular Project Structure & Setup

                    
Consolidated into this self-contained single-file web application for instant browser execution via Pyodide WebAssembly, with logical data modules for Questions, Test Cases, and Trainer Solutions.

                    
python-function-lab/
├── index.html          # Complete Single-File App (UI + Pyodide Simulator)
├── ARCHITECTURE:
│   ├── SHEETS[]        # 4 Function Worksheet Definitions
│   ├── QUESTIONS[]     # 40 Scenario Problems + Hints + Test Cases + Solutions
│   ├── Pyodide VM      # Sandboxed Client-Side Python 3.11 Runtime
│   └── Evaluator       # Structure (0.5) + Logic (1.0) + Test Cases (1.0)
└── backend/app.py      # Optional Production Flask + SQLite Evaluator

                


                

                    
Security & Storage Architecture Note

                    
    
                        
  • 
                            Client-Side LocalStorage Disclaimer: Browser localStorage is ideal for auto-saving student code drafts locally, but is inspectable by tech-savvy users. For proctored high-stakes academy exams, deploy the Flask + SQLite backend below so test cases and trainer solutions stay strictly server-side.
                        
    • 
                        
  • 
                            Sandboxed Code Execution: Both the browser Pyodide VM and the Flask subprocess runner enforce strict execution timeouts and block dangerous system calls (os, subprocess, file I/O) to prevent infinite loops or server compromise.
